# 飞控板原理图确认笔记（v4 — 修订版）

## 板子基本信息
- MCU：STM32F405RGT6（LQFP64）
- 板子尺寸：44×44mm（30.5×30.5mm安装孔距，与ESC叠装stack）
- 手焊最小封装：0603，细间距IC交嘉立创SMT
- EDA工具：嘉立创EDA Pro

---

## 一、CH340X（USB转串口 + 一键下载）

### 芯片信息
- 型号：CH340X（ESSOP10），替代原CH340E
- 替代理由：CH340X的Pin 6（TNOW）可通过外加下拉电阻切换为DTR#增强模式，配合RTS#实现一键串口下载；CH340E的TNOW无此功能

### 引脚连接
- Pin 1 (UD+) → USB Type-C D+
- Pin 2 (UD-) → USB Type-C D-
- Pin 3 (GND) → GND
- Pin 4 (RTS#) → MCU NRST（直连，用于一键下载时触发MCU复位）
- Pin 5 (CTS#) → 悬空（不需要硬件流控）
- Pin 6 (TNOW/DTR#) → 4.7kΩ下拉电阻到GND + 连接BOOT0
- Pin 7 (VCC) → 3.3V + C26 100nF退耦
- Pin 8 (TXD) → MCU RX（PB11）
- Pin 9 (RXD) → MCU TX（PB10）
- Pin 10 (V3) → 3.3V + C28 100nF退耦

### 设计决策
- TX/RX直连MCU，不加防护：CH340X与MCU共用板载3.3V，同生同灭，不存在倒灌场景
- 4.7kΩ下拉电阻（可选范围3~5.6kΩ）：触发CH340X DTR#增强模式，兼做BOOT0默认下拉
- VCC和V3均接3.3V：3.3V供电模式下V3需连接VCC

### 一键下载原理
- 正常运行：DTR#默认不输出，BOOT0被4.7kΩ拉低，RTS#默认高，MCU从Flash启动
- 烧录模式：上位机设置DTR#高（BOOT0拉高）→ RTS#低再高（触发NRST复位）→ MCU进入bootloader → UART烧录
- 注意：MODEM数据与引脚电平是反相的

## 二、MCU引脚（NRST / BOOT0）

### NRST
- 接100nF对地电容（滤EMI噪声，防止电机/ESC干扰触发意外复位）
- 直连CH340X RTS#（一键下载时触发复位）

### BOOT0
- 接CH340X TNOW/DTR#
- 通过4.7kΩ下拉电阻到GND
- 默认低电平 → 从Flash启动
- DTR#拉高时 → 进入bootloader
- 原方案（焊锡跳线）已废弃，改用CH340X自动控制

### BOOT1（PB2）
- 接10kΩ下拉电阻到GND（0603封装）
- 确保烧录模式（BOOT0=1）时BOOT1=0，从System Memory启动进bootloader
- 防止EMI环境下浮空引脚被噪声拉高导致误进SRAM启动

## 三、晶振电路（HSE 16MHz）

- 晶振：16MHz无源四脚晶振（3225封装），CL=20pF
- Pin 1 → OSC_IN（PH0），Pin 3 → OSC_OUT（PH1），Pin 2和Pin 4 → GND
- 负载电容：C29、C30各33pF，分别接在OSC_IN和OSC_OUT到GND
- 计算：CL=20pF，C_stray取3~5pF，C_ext=2×(20-C_stray)=30~34pF，33pF合理

## 四、IMU1（ICM-42688P，SPI1）

- Pin 1 (SDO/SA0) → MISO（PA6）
- Pin 14 (SDX) → MOSI（PA7）
- Pin 13 (SCX) → SCK（PA5）
- Pin 12 (CSB) → CS（PC4，GPIO输出，低电平选中，同时选择SPI模式）
- Pin 4 (INT1) → MCU GPIO（PA4，EXTI外部中断，数据就绪触发）
- Pin 5 (VDDIO) → 3.3V + C18 100nF + 【v4新增】2.2µF bulk电容
- Pin 8 (VDD) → 3.3V + C19 100nF + 【v4新增】2.2µF bulk电容
- Pin 6 (GNDIO) → GND
- Pin 7 (GND) → GND
- Pin 2 (ASDx)、Pin 3 (ASCx)、Pin 10 (OCSB)、Pin 11 (OSDO) → 悬空（OIS接口，不需要）
- Pin 9 (INT2) → 悬空（单中断线够用）

## 五、IMU2（ICM-42688P，SPI3，冗余）

### 设计目的
- 双IMU冗余：一颗数据异常时自动切换，避免单点故障导致炸机
- 交叉验证：检测传感器漂移或故障
- 商业飞控标配方案（Matek H743等），展示冗余系统设计能力

### 引脚连接
- SPI3_SCK → PC10（AF6）
- SPI3_MISO → PC11（AF6）
- SPI3_MOSI → PC12（AF6）
- IMU2 CS → PB3（GPIO Output）
- IMU2 INT1 → PA15（GPIO EXTI）

### 外围电路
- 与IMU1完全相同：VDDIO + VDD各100nF去耦到GND + 【v4新增】各2.2µF bulk电容
- CSB接MCU GPIO（PB3），低电平选中
- INT1接PA15（EXTI中断）
- ASDx、ASCx、OCSB、OSDO、INT2 → 悬空
- 交嘉立创SMT贴片

### ⚠️ JTAG引脚释放
- PB3默认功能为JTDO，PA15默认功能为JTDI
- 固件中将这两个引脚配置为GPIO模式，JTAG自动释放
- SWD调试（PA13/PA14）不受影响

## 六、【v4重构】Buck电路（TPS54560DDAR，VBAT→5V）

### 芯片信息
- 型号：TPS54560DDAR（TI，HSOP-8 PowerPAD）
- 60V输入，5A输出能力，非同步Buck，外部补偿，current mode control
- 替换原RT8289（34V耐压，6S余量不足）。TPS54560耐压60V，6S完全无忧
- 代价：需额外设计频率设定电阻和外部补偿网络

### 设计参数
- VOUT = 5V，VIN = 14.8V~25.2V（4S~6S）
- IOUT设计值 = 1A（实际峰值~515mA，留100%余量）
- f_SW = 400kHz

### 引脚连接
- Pin 1 (BOOT)：C_BOOT 0.1µF（X5R/X7R，≥10V）接到SW (Pin 8)
- Pin 2 (VIN)：接VBAT + 输入电容组
- Pin 3 (EN)：悬空（内部1.2µA上拉，自动启动，内部UVLO 4.3V生效）
- Pin 4 (RT/CLK)：R_T 243kΩ接GND（设定f_SW=400kHz）
- Pin 5 (FB)：R_HS 53.6kΩ + R_LS 10.2kΩ分压（VOUT=5V，VREF=0.8V）
- Pin 6 (COMP)：补偿网络 R4 7.5kΩ串C5 39nF，并联C8 100pF到GND
- Pin 7 (GND)：接GND
- Pin 8 (SW)：接续流二极管阴极 + L 33µH电感到输出
- PowerPAD：多via连接GND平面（散热+电气GND）

### 外围器件

**电感：**
- L = 33µH，I_sat≥2A，DCR≈190mΩ
- 选型计算：L_min = (VIN(max)-VOUT)/(IOUT×K_IND) × VOUT/(VIN(max)×f_SW) = (25.2-5)/(1×0.3) × 5/(25.2×400k) = 33.4µH
- 纹波电流 ΔI_L = 0.3×1A = 300mA > 150mA下限 ✓
- 峰值电感电流 = 1+0.15 = 1.15A

**续流二极管：**
- D1 B560C（60V Schottky，SMA封装，Vf=700mV@5A）
- 原SS54（40V）在6S下余量1.59倍刚好卡线，B560C余量更充裕
- 实际负载<1A，二极管工作极轻松

**输入电容：**
- C_IN ×3：4.7µF/50V MLCC（GRM31CR71H475KA12，1206 X7R）+ C_IN_HF 100nF
- 有效电容（25.2V DC bias降额~20%）≈ 11.3µF >> datasheet要求3µF ✓
- 输入纹波电压：ΔV_IN = IOUT×0.25/(CIN×f_SW) = 1×0.25/(11.3µ×400k) = 55mV < 1% VIN ✓
- 输入RMS纹波电流：0.47A，电容额定值远超 ✓
- 0.25为worst case占空比因子D×(1-D)最大值

**输出电容：**
- C_OUT ×3：47µF/6.3V MLCC（GRM31CR60J476ME19，1206）+ C_OUT_HF 100nF
- 5V DC bias下实际18.5µF/颗（SimSurfing实测），3颗有效55.5µF
- ESR @ 400kHz = 2mΩ/颗，3颗并联0.67mΩ（SimSurfing实测）
- 最严格约束（Eq 33能量吸收）：15.2µF，55.5µF远超 ✓

**Bootstrap电容：**
- 0.1µF，X5R/X7R，≥10V，BOOT-SW之间
- 为高侧MOSFET栅极提供驱动电荷（Qg≈3nC，电压损失=30mV可忽略）
- TPS54560内部集成bootstrap充电二极管

**反馈分压：**
- R_HS = 53.6kΩ，R_LS = 10.2kΩ（均1%精度，0603）
- R_HS = R_LS × (VOUT-0.8)/0.8 = 10.2k×5.25 = 53.55kΩ
- 分压电流 = 0.8V/10.2kΩ = 78µA >> FB引脚输入电流50nA ✓

**频率设定：**
- R_T = 243kΩ（0603），RT/CLK引脚到GND
- R_T = 101756/f_SW^1.008 = 242kΩ，标准值243kΩ
- 最大开关频率验证：Eq 9 pulse skip上限 = 1.69MHz，Eq 10 foldback上限 = 5.23MHz，400kHz远低于两者 ✓

**补偿网络（Type 2A，COMP-GND之间）：**
- R4 = 7.5kΩ（串联），C5 = 39nF（串联），C8 = 100pF（并联）
- Modulator pole：f_p(mod) = IOUT/(2π×VOUT×COUT) = 1/(2π×5×55.5µ) = 573Hz
- ESR zero：f_z(mod) = 1/(2π×0.67m×55.5µ) = 4.3MHz（远离crossover，无影响）
- Crossover目标：f_co = 20kHz
- R4 = (2π×f_co×COUT/gmps)×(VOUT/(VREF×gmea)) = 7.3kΩ → 标准值7.5kΩ
- C5 = 1/(2π×R4×f_p(mod)) = 37nF → 标准值39nF（零点对齐modulator pole）
- C8 = max(COUT×RESR/R4, 1/(R4×f_SW×π)) = max(5pF, 106pF) → 标准值100pF
- IC参数：gm_ea=350µA/V, gm_ps=17A/V, Aol=10000V/V, VREF=0.8V
- C5比典型应用（4700pF）大：因IOUT=1A轻负载导致modulator pole低至573Hz

**EN引脚：**
- 悬空，内部1.2µA上拉自动启动
- 内部UVLO 4.3V，4S最低12V / 6S最低18V远高于此阈值
- 无需外部分压电阻

### 电源指示灯
- GL0603UR01 LED + R5 1kΩ（约3mA）

### VBAT ADC分压
- R3 75kΩ（上）+ R4_ADC 10kΩ（下），1%厚膜电阻
- 中点接MCU ADC引脚（PC0，ADC1_IN10）
- 中点加100nF电容到GND（分压电阻并联等效~8.8kΩ充当滤波电阻，截止频率约180Hz）
- 兼容4S~6S：6S满电25.2V→2.96V，4S满电16.8V→1.98V，4S空电12V→1.41V
- 均不超3.3V
- 100nF滤波电容的GND紧靠MCU VSSA，远离Buck区域

### 【v4变更】TVS保护
- SMAJ20A已删除
- 原设计中SMAJ20A用于保护RT8289（34V耐压）免受反电动势尖峰
- 现TPS54560耐压60V，配合ESC端680µF电容吸收尖峰，无需额外TVS

## 七、【v4重构】LDO电路（双TLV75733PDBVR，5V→3.3V）

### 架构变更
- 原方案：单颗RT9013-33GB（500mA）
- 新方案：双TLV75733PDBVR（1A/颗），3.3V_Clean + 3.3V_Dirty隔离供电
- 变更原因：SD卡burst写入时百毫安级突发电流会在3.3V轨道上产生纹波，耦合到IMU Gyro数据中，影响PID调试

### 7.1 3.3V_Clean（TLV75733PDBVR #1）

**负载：** MCU（STM32F405）、双ICM-42688P
**峰值电流：** ~152mA
**电容配置：**
- VIN端：1µF + 100nF（紧贴VIN引脚）
- VOUT端：1µF + 100nF
**VDDA磁珠供电：** 3.3V_Clean经BLM18KG601SN1磁珠 → VDDA + C39 100nF + C40 1µF

### 7.2 3.3V_Dirty（TLV75733PDBVR #2）

**负载：** SD卡（burst写入200mA peak）、ELRS接收机（~50mA）
**峰值电流：** ~250mA
**电容配置：**
- VIN端：1µF + 100nF（紧贴VIN引脚）
- VOUT端：1µF（LDO端）
- SD卡端：10µF + 100nF（紧贴卡座VDD引脚，吸收burst写入电流）

### 7.3 PCB Layout要求
- SD卡及其LDO放在板子角落/边缘
- SD卡的GND独立打via回到主GND，回流路径不得穿过MCU或IMU下方的地平面
- 两颗LDO使用相同型号减少BOM种类，方便嘉立创贴片

## 八、USB Type-C接口

### 引脚连接
- VBUS (A4B9) → SS54肖特基二极管 → 板载5V rail + C25 100nF + C24 4.7µF
- CC1 (A5) → R6 5.1kΩ下拉到GND（UFP/sink标识）
- CC2 (B5) → R7 5.1kΩ下拉到GND
- DP1 (A6) + DP2 (B6) → 并联 → D+（CH340X UD+）
- DN1 (A7) + DN2 (B7) → 并联 → D-（CH340X UD-）
- SBU1 (B8)、SBU2 (A8) → 悬空（USB 2.0不使用）
- GND (A1B12) → GND
- EH1~EH4 → GND（EMI屏蔽）

### 电源路径设计
- SS54二极管（USB VBUS侧）：防止Buck 5V反灌到USB口烧电脑
- Buck侧不加二极管：USB侧有二极管已足够隔离
- 不插电池时USB可单独给板子供电（~4.5V→LDO→3.3V，桌面调试用）
- 同时插电池和USB时：Buck 5V > USB经二极管4.5V，Buck自动接管

### 【v2新增】USB ESD保护
- 芯片：USBLC6-2（SOT-23-6），双路TVS阵列
- VBUS引脚接USB VBUS（5V），GND接GND
- I/O1接D+，I/O2接D-（芯片内部对称，无方向性要求）
- VBUS引脚旁加100nF去耦电容（若layout上距连接器C25足够近可省略，但建议保留）
- TVS二极管并联在信号线与电源/地之间，正常时高阻不影响信号，静电时导通泄放
- 结电容3.5pF/通道，USB 2.0可接受
- 放置原则：物理位置尽量靠近USB连接器，挡在连接器和CH340X之间
- 不需要额外串联电阻或并联电容，避免影响USB信号完整性

## 九、ESC信号连接器

- 连接器：SH1.0 8pin立插（ZX-SH1.0-8PLT）
- 引脚顺序：
  1. Tele（ESC Telemetry，单线串口，接MCU UART5_RX / PD2）
  2. CRT（电流传感器模拟输出，接MCU ADC1_IN11 / PC1）
  3. S4（电机4 PWM/DSHOT信号，PA11 / TIM1_CH4）
  4. S3（PA10 / TIM1_CH3）
  5. S2（PA9 / TIM1_CH2）
  6. S1（PA8 / TIM1_CH1）
  7. VBAT+（电池电压直通，飞控板从此取电）
  8. GND

### 【v2新增】电机PWM输出安全下拉
- PA8、PA9、PA10、PA11各加100kΩ下拉电阻到GND（0603封装）
- 目的：MCU在reset/bootloader期间GPIO处于Hi-Z状态，下拉电阻确保PWM线默认低电平，防止电机意外启动
- 正常工作时影响可忽略：高电平期间漏电仅33µA/通道，输出电压衰减<1mV
- ESC接收电压信号，100kΩ对信号幅度无影响

## 十二、GPS/传感器子板

### 子板概述
- 独立PCB，通过SH1.0 8pin连接器与飞控板连接
- 远离电机，减少磁干扰和振动影响
- 板上配LDO（RT9013-33GB），5V→3.3V本地稳压

### 连接器引脚定义（飞控板侧SH1.0 8pin）
  1. 5V（飞控板Buck输出，子板LDO输入 + 蜂鸣器驱动电源）
  2. GND
  3. UART4_TX（PA0，MCU→GPS）
  4. UART4_RX（PA1，GPS→MCU）
  5. GPS PPS（PC3，GPIO EXTI）
  6. I2C1_SCL（PB6）
  7. I2C1_SDA（PB7）
  8. Buzzer PWM（PB5，TIM3_CH2）

### 【v2新增】I2C1总线上拉电阻
- PB6（SCL）和PB7（SDA）各加4.7kΩ外部上拉电阻到3.3V（子板侧）
- I2C为open-drain总线，芯片内部上拉太弱（通常几十kΩ级别），200kHz速率下波形无法正常建立
- 上拉电阻放在子板本地3.3V LDO输出端，就近供电
- 0603封装

### GPS模块（ATGM336H-5N71）
- 卫星系统：GPS + BDS + GLONASS三模
- 接口：UART，默认9600波特率，NMEA协议
- 引脚：VCC（3.3V）、GND、TX、RX、PPS
- PPS：定位成功后输出秒脉冲，接飞控板PC5（GPIO EXTI）
- 供电：子板本地3.3V LDO

### 【v2新增】GPS天线净空区
- ATGM336H-5N71使用陶瓷贴片天线，天线正上方及周围需保持copper keep-out区域
- PCB layout阶段在天线区域避免铺铜（顶层和底层均需留空），否则严重影响接收灵敏度
- 子板设计时将GPS模块放置在板边缘，天线朝外

### 气压计（BME280，I2C模式）
- 功能：温度 + 湿度 + 气压三合一（气压部分与BMP280寄存器兼容）
- 关键指标：相对精度±0.12hPa，噪声滤波后1.7cm高度分辨率
- I2C地址：0x76（SDO接GND）
- 引脚接法（I2C模式）：
  - Pin 1 (GND) → GND
  - Pin 2 (CSB) → VDDIO/3.3V（选择I2C模式）
  - Pin 3 (SDI) → SDA（I2C1_SDA / PB7）
  - Pin 4 (SCK) → SCL（I2C1_SCL / PB6）
  - Pin 5 (SDO) → GND（地址0x76，不可悬空）
  - Pin 6 (VDDIO) → 3.3V + 100nF去耦
  - Pin 7 (GND) → GND
  - Pin 8 (VDD) → 3.3V + 100nF去耦
- 安装注意：sensing port不可堵死，需通气；上方贴开孔海绵挡桨洗气流

### 磁力计（QMC5883L，I2C）
- I2C地址：0x0D（固定，与BME280的0x76不冲突）
- 与BME280共用I2C1总线（PB6 SCL / PB7 SDA）
- 总线速率：400kHz
- 供电：子板本地3.3V LDO

### 蜂鸣器（无源电磁式）
- 额定电压：5V（工作范围3V~7V）
- 工作电流：80mA，声压85dB，谐振频率2.048kHz
- 驱动电路：NPN三极管开关 + 基极限流电阻（~1kΩ）+ 续流二极管
- 三极管基极接飞控板PWM信号（PB5 / TIM3_CH2）
- 蜂鸣器电源从子板5V直接取（不经LDO）

### 子板LDO电路（RT9013-33GB，5V→3.3V）
- VIN：接连接器5V
- VOUT：3.3V，供GPS模块、BME280、QMC5883L
- EN：接VIN
- 输入输出电容参照飞控板LDO配置

## 十四、ADC信号调理

### VBAT分压滤波
- R3 75kΩ（上）+ R4_ADC 10kΩ（下）分压中点加100nF电容到GND
- 分压电阻并联等效~8.8kΩ自然充当滤波电阻，截止频率约180Hz
- ADC采样时间设≥144 cycles，补偿较大源阻抗

### CRT电流检测滤波
- ESC CRT输出规格：11.75mV/A
- 信号到ADC引脚（PC1）之间加RC低通滤波：R=100Ω + C=100nF
- 截止频率≈16kHz，滤除ESC开关噪声，保留低频电流信号
- 100Ω源阻抗远低于ADC限制，不影响采样精度

## 十六、设计原则备忘

1. **硬件确认优先于引脚分配**：先确定所有模块芯片和接口需求，再统一做引脚分配
2. **6S兼容性贯穿整个电源链路**：分压电阻、输入电容耐压、Buck IC耐压、续流二极管耐压按最高电压设计
3. **CubeMX统一分配引脚**：避免Timer/DMA/UART/SPI资源冲突
4. **I2C共用总线确认地址不冲突**：BME280=0x76，QMC5883L=0x0D
5. **BME280 SDO引脚不可悬空**：必须接GND或VDDIO，否则I2C地址undefined
6. **子板本地稳压优于长线拉3.3V**：减少压降，电源更干净
7. **电磁式蜂鸣器需续流二极管**：线圈断电反向EMF会击穿三极管
8. **双IMU使用独立SPI总线**：避免共用SPI的时序竞争，提高可靠性
9. **JTAG引脚复用需固件释放**：PB3（JTDO）和PA15（JTDI）默认JTAG功能，配置为GPIO模式即可释放，SWD不受影响
10. **SD卡未使用数据线上拉**：DAT1/DAT2接10kΩ上拉到VDD，符合SD协议空闲高电平规范
11. **ADC源阻抗匹配**：VBAT分压等效8.8kΩ需延长采样时间；CRT滤波100Ω远低于限制
12. **【v2新增】I2C总线需外部上拉**：open-drain总线芯片内部上拉不够，外加4.7kΩ上拉到3.3V
13. **【v2新增】PWM输出需安全下拉**：Hi-Z期间100kΩ下拉保证电机不动，正常工作影响可忽略
14. **【v2新增】USB接口需ESD保护**：人手可触及的接口必须加TVS阵列，保护后级芯片
15. **【v2新增】GPS陶瓷天线需净空区**：天线上方及周围PCB不铺铜，否则灵敏度严重下降
16. **【v2新增】SD卡供电需bulk电容**：burst写入电流波动大，100nF去耦不够，加10µF bulk
17. **【v3新增】VDDA须经ferrite bead隔离**：磁珠串联在VDD和VDDA之间，配合去耦电容构成LC滤波，防止数字噪声污染ADC参考电压
18. **【v3新增】BOOT1(PB2)须显式下拉**：浮空状态在EMI环境下可能误触发SRAM启动模式
19. **【v3新增】DMA stream须提前规划**：同时工作的外设不能共享stream，CubeMX可实时验证冲突
20. **【v4新增】双LDO隔离供电**：SD卡burst电流不得耦合到IMU/MCU电源轨，双LDO物理隔离Clean和Dirty域
21. **【v4新增】IMU需bulk电容**：ICM-42688P的VDD和VDDIO旁各加2.2µF bulk电容，降低Gyro底噪
22. **【v4新增】Buck外部补偿需匹配实际参数**：电感、电容、负载电流不同于典型应用时，补偿网络必须用自己的参数重新计算，不能直接抄datasheet典型值
23. **【v4新增】MLCC DC bias降额必须查SimSurfing**：标称容值在工作电压下大幅缩水，电源设计必须用降额后的实际值
