# PCB 设计说明

---

## 四层板叠层

### 经典叠层 Top → GND → Power → Bottom 规范

- **L2 GND层**：保持完整，不割裂。所有信号回流电流走L2，任何切口都会迫使回流绕道，产生环路面积和EMI
- **L3 Power层**：按网络分区铺铜，VBAT/5V/3.3V各自占一块区域，区域之间留间隙，不走信号线
- **Top层信号**：优先在Top层走完，回流在正下方L2 GND层，路径最短
- **Bottom层信号**：Bottom层信号以L3为参考平面，但L3被Power分区间隙割裂，回流路径不连续，所以避免走高速/敏感信号（SPI、USB、晶振），如果确定信号仅在Bottom层，不会换层走线，也可以直接在Bottom层走
- **换层过孔**：信号换层时，在换层过孔旁就近放一个GND缝合过孔，给回流电流提供最短路径
- **去耦电容**：放Top层靠近引脚，过孔直连L2 GND和L3 Power，不绕远

### 飞控板推荐叠层 Top → GND → GND → Bottom

- 两个内层均为GND，牺牲独立Power平面
- 回流路径更完整，对IMU屏蔽更好
- 代价：电源走线需在Top/Bottom层手动布
- Top → GND → GND → Bottom叠层下，Top和Bottom层信号都有紧邻的GND参考平面，回流完整性比经典叠层更好。但代价不只是"电源走线需手动布"，还有一点：两个GND层之间需要大量缝合过孔保持等电位，否则L2和L3的GND之间会形成谐振腔
- 适用场景：小板（36×36mm）、电源网络简单、IMU对噪声敏感

### L3 Power层规划

- Power层不是整层一个网络的完整覆铜，而是按网络分区铺铜：VBAT一块区域、5V一块区域、3.3V一块区域，区域之间有间隙隔开
- 各电源区没有硬性面积要求（飞控电流等级下1oz铺铜载流能力远远富余），关键是：铜区能覆盖到所有需要该网络的过孔位置，且铜区不能有窄颈（bottleneck）
- 电源铜区保持简洁的大块形状（矩形或近似矩形），如果某个器件的电源过孔落在铜区范围外，用Top/Bottom层走线连过去，不要扭曲Power层铜区的形状去迁就它
- **L3空余区域铺GND（推荐）**：Power分区之间的空余区域补上GND铺铜，可以为Bottom层信号提供GND参考平面，改善回流路径。注意GND铺铜区域必须通过缝合过孔连接到L2 GND平面，否则是浮铜无意义；和电源铜区之间保持足够间距；铺完检查GND铜区是否足够大且连续，碎片化的小铜块效果有限不如删掉
- 规划顺序：先完成Top层器件布局 → 看哪些区域集中了VBAT/5V/3.3V器件 → Power层按分布划大块 → 剩余空间铺GND

## 设计规则

### 安全间距（copperThickness1oz）

- 导线-焊盘、导线-过孔：0.127mm（5mil），给MCU LQFP64 0.5mm pitch出线留空间
- 铺铜/内电层-其他：0.2mm（8mil），铺铜避让收紧，回流路径更连续
- 导线-导线：0.102mm（4mil）保留，但实际布线尽量用6mil，4mil只用在不得不挤的地方（如QFP指间）

### 其他间距（otherClearance）

- 元件到元件：0.203mm（8mil），防回流焊桥连，留手焊/返修空间
- 插件焊点到SMD元件：0.508mm（20mil），通孔焊接热影响区安全距离（当前板子通孔焊盘仅有SWD调试和测试点，信号级，20mil足够）
- 钻孔到钻孔：0.3mm，保留

### 线宽

- 顶层/底层：最小5mil，默认10mil，保留
- 内层1（GND）：保留默认（整层铺铜基本不走线）
- 内层2（Power）：最小10mil，默认20mil（防止误拉细电源线）

### Net Class（电源网络线宽）

| Net Class | 包含网络 | 最小线宽 | 默认线宽 |
|---|---|---|---|
| Default | 所有信号 | 5mil | 10mil |
| Power | VBAT, 5V | 15mil | 20mil |
| Power_3V3 | 3.3V_Clean, 3.3V_Dirty | 10mil | 15mil |

- 3.3V电流小（Clean约200-300mA，Dirty约100-200mA），10-15mil足够，20mil在MCU引脚密集区浪费空间

### 内电层（innerPlane）/ 铺铜区域（copperRegion）— 多层焊盘

- 内层1（GND）：发散连接，10mil发散线宽，保留（手焊需要花焊盘防热量被铜皮吸走）
- 内层2（Power）：改为直连（推荐）或发散20mil。Power层无需手焊，直连阻抗最低
- 信号网络的通孔焊盘在Power层不连接任何铺铜（Power层只铺电源网络），直连/发散设置对它们不触发

### 过孔尺寸

- 外径24mil / 内径12mil（默认），信号过孔和电源过孔统一使用，不需要单独建电源过孔规则
- 电源走线通过多个默认过孔并联提高载流能力

### 阻焊/钢网

- 阻焊（solder mask）：焊盘扩展2mil，过孔盖油（-1000，tented via），测试点扩展2mil
- 钢网（paste mask）：焊盘扩展0，测试点不开钢网（-1000）
- 过孔盖油是嘉立创免费选项，防止焊锡流入过孔、防氧化、防短路

## 器件布局原则

### Top层器件

- MCU、Buck、LDO、晶振必须放Top层
- MCU是走线最密集的器件，放Bottom层会导致过孔爆炸
- Buck需要紧凑布局，放Bottom层换层会增大环路面积
- 晶振负载电容必须在Top层紧贴MCU OSC引脚

### Bottom层器件

- SD卡座、TypeC连接器、CH340X可放Bottom层
- CH340X放Bottom层是合理布局：Type-C也在Bottom层，USB D+/D-差分信号可以在Bottom层直接走完不换层；CH340X到MCU的UART（USART3）是低速单端信号，通过via换层到Top层完全没问题
- 适合放Bottom层的：不敏感无源器件、连接器、走线简单的器件
- 不适合放Bottom层的：IMU、晶振、高速器件

### IMU布局

- 放板子几何中心，远离减震孔（减震孔附近板子形变最大）
- 两个IMU间距建议5mm以上，分散在不同位置可以区分PCB局部应力/振动模态的影响，提高冗余校验的有效性。如果两个IMU紧贴在一起，受到相同的局部干扰，冗余就没意义了
- IMU正下方严格禁布器件和走线，保持GND铺铜完整
- IMU边缘外2~3mm范围尽量避开，空间紧张可放不敏感无源器件，不放高频走线和开关电源器件
- 两组SPI总线（SPI1主IMU、SPI3备用IMU）走线之间保持间距，不要并行走太长，避免主备IMU之间信号串扰

### 晶振布局

- 紧贴MCU，走线越短越好
- 晶振下方Bottom层保持GND铺铜完整，不放器件和走线
- 做包地处理

### 晶振包地处理详解

- **晶振是两端器件**（就振荡信号而言）：两个信号引脚分别接OSC_IN和OSC_OUT，AC电流从一端进另一端出。GND引脚（通常Pin2/Pin4）是金属外壳接地，作用是EMI屏蔽，不参与振荡电流回路
- **AC电流回路**：
  - 回路1：MCU OSC_IN → 负载电容C1 → GND → GND铺铜 → MCU VSS → 内部放大器 → OSC_IN
  - 回路2：MCU OSC_OUT → 负载电容C2 → GND → GND铺铜 → MCU VSS → 内部放大器 → OSC_OUT
  - 两个回路共享GND回流路径，C1 GND、C2 GND、晶振外壳GND、MCU VSS在GND铺铜上必须连续且短
- **负载电容GND焊盘必须单独打GND过孔**：就近提供回流电流最短路径到内层GND平面。不能靠周围包地孔替代——包地孔在外围，回流电流要先横向走到包地孔位置再打到内层，增大环路面积
- **负载电容GND焊盘不能被OSC走线包围隔离**：OSC走线从电容外侧走，保持电容GND和晶振GND之间铺铜连续
- **不要在晶振器件占位区域内部穿线**：不管是其他信号线还是晶振自己的OSC走线，都不要在GND焊盘和OSC焊盘之间穿来穿去。OSC走线从焊盘直接向外引出，走最短路径到MCU
- **包地孔**：在晶振+负载电容区域外围打一圈GND过孔，把Top层GND铺铜和内层GND平面缝合，形成屏蔽笼。作用是双向隔离——防止晶振辐射干扰周围信号，防止外部噪声（如Buck开关噪声）耦合进来
- **包地孔间距**：2-3mm足够。屏蔽效果取决于间距相对于噪声波长的比例（衍射原理），16MHz波长约18.75米，即使10次谐波（160MHz）波长仍有1.875米，2-3mm间距远小于λ/20。过密反而浪费空间且避让环可能破坏GND平面
- **包地孔缺口**：包地圈在OSC走线引出到MCU的那一侧留缺口（不可能完全封闭），缺口朝MCU方向，背对噪声源
- **晶振GND焊盘**：每个GND焊盘旁边打1个GND过孔即可（外壳屏蔽接地，不走信号电流，1个过孔足够）

### 其他布局原则

- JST-SH针座空引脚悬空即可，不需要接GND
- PWM下拉电阻靠近MCU引脚放，可放Bottom层

## 电源走线

### Buck布局优先级

1. **输入电容**：必须紧贴Buck IC输入引脚，走线距离越短越好；输入电容到Buck IC这段有高频开关电流，寄生电感会产生电压尖峰
2. **SW环路**：IC的SW引脚、电感输入端、续流二极管阴极三者汇聚于同一个SW node，这个节点的铜面积要最小化，三个器件围绕SW node紧凑布局，环路面积最小化；环路面积越大辐射越强
3. **输出电容**：尽量靠近Buck IC输出引脚，稍远影响可接受
4. **FB采集点**：放在输出电容之后，采集滤波后的稳定电压

### Buck IC下方

- 不走信号线，不走电源线
- Buck IC（TPS54560DDAR）底部exposed pad接GND，下方打thermal via到GND层散热
- Bottom层保持GND铺铜完整，散热面积越大越好
- SW节点高频开关噪声会耦合到下方走线

### VBAT走线

- VBAT是直流大电流走线，可走L3 Power层
- 换层打2~3个并联过孔，不用单个大过孔
- 并联过孔优于大过孔：载流能力叠加，分布灵活，还能兼顾GND缝合

### 输入电容电源过孔

- VBAT过孔在输入电容组入口处打一组（2个并联）即可，不需要每个输入电容旁边都打
- 原因：VBAT过孔走的是直流补充电流（电池给电容"充电"），频率低，对位置不敏感。高频开关电流只在输入电容和Buck IC之间本地循环，不经过VBAT过孔
- **反过来，每个输入电容的GND焊盘才需要就近打GND过孔**——高频开关电流的回流路径经过每个电容的GND焊盘，对位置敏感

### 输入/输出电容 GND

- 输入电容GND和输出电容GND要尽量短接在一起
- 原因：高侧FET导通瞬间，电流路径是 输入电容+ → VIN pin → 内部FET → SW pin → 电感 → 输出电容+ → 输出电容GND → 输入电容GND。这个环路中输入电容GND到IC PGND这段是高频电流的关键瓶颈，所以输入电容GND要直接短接到IC的PGND pad，输出电容GND也就近连到同一个GND节点，缩小这段GND走线的寄生电感才能降低高频噪声
- 电池GND是直流路径，对其距离不敏感
- **Top层GND铺铜连续性优先**：续流二极管GND、输入电容GND、Buck IC GND在Top层铺铜上直接连成一片，高频开关电流在Top层就能闭环，不一定需要通过过孔绕到内层再回来。过孔是补充路径，不是唯一路径

### 续流二极管GND

- GND焊盘打2个过孔足够（电流约1A）
- 关键不是多打过孔，而是确保Top层铺铜把续流二极管GND、输入电容GND、Buck IC GND连成一片

### 电源并联过孔铺铜技巧

- 打两个并联过孔后，在过孔之间画一个矩形铺铜区域，把两个焊盘环连成一整块铜皮
- 过孔负责垂直方向层间导电，矩形铺铜负责水平方向增大载流面积，两者互补
- 适用于VBAT和5V的电源过孔

### LDO

- 两个LDO并联从5V取电，不串联
- 串联会导致压差余量减少，影响第二个LDO正常工作

## 过孔使用原则

### 载流能力参考（0.3mm drill, 1oz铜）

| 电流 | 过孔数 |
|---|---|
| < 0.5A | 1个 |
| 0.5 - 1A | 2个 |
| 1 - 2A | 3-4个 |
| 2 - 5A | 5-10个 |

- 过孔载流能力只看电流，和电压无关（电压影响绝缘间距，PCB常见电压下不是瓶颈）

### 过孔并联与GND平面的平衡

- 过孔并联越多，自身等效寄生电感越低（类似电阻并联，N个过孔等效电感 ≈ 单个/N）
- 但每个过孔在GND层有避让环（anti-pad），过孔太密会把GND铺铜切断，导致其他信号的回流路径被迫绕道，间接增加那些信号的回流电感
- 结论：够用就行，不要无脑堆

### GND过孔共用原则

- 同一区域内多个GND焊盘如果在Top层铺铜上已经连成一片：共用几个GND过孔即可，少打过孔减少避让环，GND平面更完整
- 如果GND焊盘之间被走线切断、铺铜不连续：每个焊盘必须就近打自己的GND过孔
- 判断方法：铺完铜之后看焊盘之间有没有连续铜皮相连

### 过孔类型

- 标准PCB过孔（through-hole via）：从Top层打穿到Bottom层，贯通所有层，不能选择连接特定层
- 盲孔（blind via）：从表层到某个内层，不打穿
- 埋孔（buried via）：只在内层之间，不到表层
- 盲孔和埋孔嘉立创支持但收费更高、工艺复杂，飞控板用不上，通孔via配合覆铜分区即可

## SPI走线（ICM-42688P）

### 基本原则

- ICM-42688P SPI时钟最高24MHz，不算真正的"高速"（波长12.5米，20mm走线远小于λ/10，传输线效应不需要考虑）
- 等长不必须（SPI同步协议，24MHz时钟周期41.7ns，几mm长度差造成约0.1ns延迟可忽略）
- 走线保持短（<20mm）、下方有连续GND参考平面

### 信号间距优先级

| 信号对 | 间距要求 | 理由 |
|---|---|---|
| CS - SCK | 最高，保持3W | 毛刺直接导致通信中断 |
| SCK - MISO | 中等，尽量留 | 时钟耦合可能干扰数据采样 |
| MOSI - MISO | 低，踩DRC可以 | 实际影响很小 |
| SCK - MOSI | 低，踩DRC可以 | 都是MCU输出，时序同步 |

- 3W规则：中心到中心 ≥ 3倍线宽，即边到边间距 ≥ 2倍线宽（如5mil线宽，边到边至少10mil）
- 空间不够时优先保证CS间距，其他踩DRC可接受
- CS不算高速信号（通信期间保持低电平不翻转），但算敏感信号（毛刺会中断通信），从回流路径角度CS可以走Bottom层
- CS如果和SCK空间实在分不开，可以中间隔一根GND走线做屏蔽

### SCK换层

- 尽量保持在Top层
- 必须换层时：短距离（5-10mm以内），换层过孔旁紧贴GND缝合过孔，换回Top层时再打一个GND缝合过孔
- Bottom层走线参考平面是L3 Power层（可能不连续），L3空余区域铺GND可改善

### 双IMU SPI隔离

- SPI1（主IMU）和SPI3（备用IMU）两组总线走线之间保持间距，不要并行走太长

## 去耦电容

### 基本原则

- 大电容（10µF以上）滤低频，100nF滤高频，两者功能互补，混放在同一VDD引脚旁完全没问题
- 100nF穿插在大电容之间（如4.7µF - 100nF - 4.7µF）效果与排成一排相同，只要都紧贴VDD引脚

### Bottom层去耦电容

- 效果比Top层稍差（多了过孔寄生电感），但在飞控工作频率下差别不大
- 补偿方式：并联多个100nF（原本1个换成2个并联），降低等效串联电感（ESL）
- 大电容（4.7µF以上）对过孔寄生电感不敏感，放Bottom层无需额外补偿
- 磁珠同样不敏感，放Bottom层无问题

### 晶振负载电容

- 必须放Top层，紧贴MCU的OSC引脚
- 放Bottom层换层会引入过孔寄生电感，影响振荡频率精度和起振稳定性
