## 5. ESC 边界

### 5.0 ESC 内部器件（实测丝印确认）

| 器件 | 型号 | 数量 | 关键参数 |
|------|------|------|---------|
| MOSFET | Infineon BSC014N04LS | 24 颗（6/电机） | **VDS = 40V**，RDS(on) = 1.4mΩ，ID = 100A |
| 栅极驱动 | FD6288 或变体（Fortior Tech） | 4 颗（1/电机） | 三相半桥驱动，内置 200ns dead time |
| 控制 MCU | EFM8BB21F16G（推测） | 4 颗（1/电机） | BLHeli-S 固件，48MHz |

**MOSFET 耐压余量（4S 配置）**：VDS_max = 40V，VBAT_max = 16.8V（4S 满电），换相尖峰余量 = **23.2V**。

### 5.1 电流

- 单路额定 **65A**
- 悬停单电机 2.2A → **余量 30 倍**
- 单块电池限流下单电机 13.75A → **余量 4.7 倍**
- 双电池限流下单电机 27.5A → **余量 2.4 倍**

**结论：电流层面完全安全，任何电池配置下 ESC 电流余量都充足。**

### 5.2 轴距 / 线长

| 参数 | 值 |
|------|-----|
| ESC 手册轴距上限 | ≤330mm |
| 实际机架轴距 | 425mm |
| 电机出线长度 | 250mm |
| ESC 中心到电机距离 | 425 / 2 ≈ 213mm |
| 实际三相线长度 | ~250mm（出线长度，刚好够到 ESC） |
| 330mm 轴距对应线长 | ~165mm |
| 线长超标比例 | 250 / 165 ≈ **1.5 倍** |

### 5.3 轴距风险定性评估

换相电压尖峰 V_spike = L × di/dt，尖峰能量 ∝ L × I²。

| 工况 | 线长倍数 | 电流 | 尖峰能量相对设计极限 |
|------|---------|------|-------------------|
| ESC 设计目标（推测）（5315 电机，60A） | 1.0× | 60A | 100%（基准） |
| 本配置悬停（2.2A） | 1.5× | 2.2A | **0.2%** |
| 本配置单块电池上限（13.75A） | 1.5× | 13.75A | **7.9%** |
| 本配置双电池上限（27.5A） | 1.5× | 27.5A | **31.6%** |
| 本配置电机极限（64.1A） | 1.5× | 64.1A | **171%（危险）** |

### 5.4 MOSFET 耐压分析（BSC014N04LS，VDS = 40V）

MOSFET 损坏条件：VBAT + V_spike > VDS(40V)。4S 满电 VBAT = 16.8V，可承受尖峰余量 = 23.2V。

250mm 18AWG 线寄生电感约 250nH。FD6288 gate driver 内置 200ns dead time + gate 电阻限制实际 di/dt，加上 ESC 输入端电容吸收部分尖峰，实际尖峰低于理论最大值。

| 工况 | 定性尖峰幅度 | VBAT + V_spike vs 40V | 判定 |
|------|------------|----------------------|------|
| 悬停 2.2A | 极小（几伏） | ~19V | **安全，余量充裕** |
| 中油门 10-15A | 中等 | 估算 25-32V | **大概率安全** |
| 高油门 25-30A | 较大 | 接近或可能触碰 40V | **风险区域，需实测** |
| 全油门 60A+ | 很大 | 大概率超过 40V | **危险** |

**结论**：

- 悬停和中等油门（单电机 < 15A）：换相尖峰远低于 40V 耐压，**确认安全**
- 中高油门（15-30A）：理论估算接近但未超 40V，FD6288 dead time 和输入电容提供额外保护，**大概率安全但无法100%确认**
- 单电机接近 60A+：尖峰大概率超过 40V 耐压，**危险**
- 当前电池配置下，电池限流自然阻止了电流进入危险区域

## 6. 油门上限与安全策略

### 6.1 软件油门限制（已实现）

```c
#define THROTTLE_MIN  1000
#define THROTTLE_MAX  1700   // 70% 油门，后续根据 CRT 实测调整

void Motor_SetSpeed(uint8_t motor, uint16_t pulse_us){
    if (pulse_us < THROTTLE_MIN) pulse_us = THROTTLE_MIN;
    if (pulse_us > THROTTLE_MAX) pulse_us = THROTTLE_MAX;
    // ...
}
```

### 6.2 安全边界总结

| 油门范围 | 单电机电流（估算） | 风险等级 |
|---------|------------------|---------|
| 0-30% | 0-2.2A | 无风险（悬停区） |
| 30-50% | 2.2-8A | 无风险 |
| 50-70% | 8-25A | 安全（ESC 设计极限的 < 30%） |
| 70-85% | 25-45A | 需谨慎（接近双电池限流区间） |
| 85-100% | 45-64A | 危险（轴距超标 + 大电流换相叠加） |

### 6.3 建议

- PID 调试阶段：单块电池，油门上限 60%，电池天然限流兜底
- 稳定飞行阶段：双电池并联，软件油门上限 70%
- 如果未来换高 C 率大电池（解除电池限流）：**必须同时换分体 ESC 或降低软件油门上限**

## 7. 未确定项（需实测）

| 项目 | 原因 |
|------|------|
| APC 1050 + 2812 1100KV + 4S 的全油门电流 | 无厂商数据，桨型不同不可套用 HQ9x5x3 数据 |
| 油门百分比与电流的精确映射 | Current ∝ Throttle³ 是近似，需 CRT ADC 实测 |
| 250mm 线长下具体 MOSFET 耐压余量 | FET 型号已知（BSC014N04LS，VDS=40V），但实际寄生电感和 di/dt 未实测，尖峰幅度为估算值 |
| THROTTLE_MAX 的最终安全值 | 需带桨实测 CRT 电流后确定 |
