# Alpha-Flight-2.X

高性能开源四旋翼飞行器固件与硬件解决方案，适配 STM32F405 高性能飞控系统。

## 项目简介

本项目为一套完整的 10 英寸四旋翼无人机开发方案，包含底层飞控逻辑、硬件选型及配套 PCB 工程。为保障代码的模块化与安全性，飞控逻辑与电机电调调试通道（Passthrough）采用独立模块化设计。

## 核心特性

* **高性能 PID 控制**：集成微分先行（Derivative on Measurement）与动态反向计算（Back-Calculation）抗饱和逻辑，有效抑制电机满载抽搐，提升飞行稳定性。
* **硬件冗余设计**：双 IMU (ICM-42688P) SPI 冗余架构，提升传感器数据可靠性。
* **电源优化**：基于 TPS54560 的 6S 兼容电源设计，配合双 LDO 实现模拟/数字电源隔离。
* **专业工程文档**：项目内含完整的原理图、BOM 物料清单、系统控制流图及详细的电源/信号拓扑分析。

## 固件架构

- `/Flight`: 核心控制逻辑，含姿态解算与 PID 控制器。
* `/Hardware`: 底层外设驱动（DSHOT 协议、ELRS/CRSF 协议、SPI 传感器驱动等）。
* `/Passthrough`: 独立的电调调试工具，支持直接通过飞控透传电调设置。
